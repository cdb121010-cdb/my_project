## 📂 프로젝트 및 과제 목록

- [**Final_Exam (기말과제: ATmega128 기반 듀얼 모드 스탑워치 및 타이머 시스템)**](Final_Exam/)
  - **개요**: 하드웨어 타이머/카운터 1(CTC 모드 10ms 주기)과 USART1(9600bps) 비동기 시리얼 통신을 연동하여, 터미널 명령 및 푸시버튼으로 0.01초 정밀도의 스탑워치 및 카운트다운 타이머를 제어하고 4자리 FND에 동적 표시하는 임베디드 제어 시스템
  - **MCU**: Microchip / Atmel ATmega128 (14.7456 MHz)
  - **핵심 기능**: 터미널 입력 실시간 에코, 0.01초 단위 정밀 계측, 타이머 일시정지/재개(TP/TR), 동작 중 모드 실시간 상호 전환(M0/M1), 4자리 FND 동적 멀티플렉싱 및 소수점(DP) 점등 제어

▪스탑워치/ 타이머만들기
◦ PC 터미널을통해서스탑워치모드와 타이머모드를설정할수있다. 
◦ 각모드동작중일때에도터미널에서모드를변경을할수있다.
 ◦ 스탑워치모드
◦ PD0 버튼으로Start / Pause를제어한다. PD1 버튼으로스탑워치를리셋한다. 
◦ 스탑워치는7-Segment에0.01초단위까지표시되고, 최대99.99초까지표현된다. 
◦ 타이머모드
◦ PC 터미널을통해시작시간을초단위로최대99초까지입력받는다. 
◦ 터미널에서시간입력과동시에타이머가동작하고, 시간이감소되는것이0.01초단위까지7-Segment에표시된다. 
◦ 설정한시간이경과하면터미널에타이머완료메시지가표시된다. 
◦ 타이머동작중에도터미널에서시간을멈출수있다. 


▪터미널명령입력형식(※ 명령은모두대문자로입력하며, 엔터(Enter) 키로전송한다.)
 ◦ M0 : 스탑워치모드로변경
◦ M1 : 타이머모드로변경
◦ T+시간 : 타이머시간설정(예시:  T30 → 30초로설정함.)
 ◦ TP : 타이머일시정지(Pause)
 ◦ TR : 타이머동작재개(Resume)


1. M0 입력시스탑워치모드진입
◦ M0 명령입력후터미널에스탑워치모드진입메시지가출력되는지확인한다.
 ◦ 7-Segment가 00.00으로초기화(리셋) 되는지확인한다.
 2. 스탑워치Start / Pause / Reset 동작
◦ Start 동작 확인: PD0 버튼을누르면7-Segment의시간이0.01초단위로정확하게증가하는지확인한다
◦ Pause 동작확인: PD0 버튼을다시누르면시간이멈추는지확인한다. (증가중단)
 ◦ Resume 동작확인: PD0 버튼을다시누르면멈춘시간에서부터다시시간이증가하는지확인한다.
 ◦ Reset 동작확인1 : PD1을눌러도 리셋되지않는지확인한다.(동작중에리셋버튼입력무시)
 ◦ Reset 동작확인2 : PD0 버튼을눌러시간을멈춘후, PD1 버튼을누르면7-Segment가00.00으로
리셋되는지확인한다.


3. M1 입력시타이머모드진입
◦ M1 명령입력후터미널에타이머모드진입메시지가출력되는지확인한다.
 ◦ 7-Segment가00.00으로초기화(리셋) 되는지확인한다.
 4. 타이머기본동작
◦ T10 명령입력후, 7-Segment에10.00에서00.00까지시간이정확하게0.01초단위로감소하는지확인한다.
 ◦ 10초가모두경과한후, 터미널에타이머동작완료메시지가출력되는지확인한다.


5. 타이머TP / TR 명령동작
◦ T15 명령입력후, 7-Segment에15.00에서시간이감소하는지확인한다.
 ◦ 타이머완료전에TP 명령을입력하면, 타이머일시정지메시지가출력되고, 7-Segment의시간이
현재시점에서멈추는지확인한다.
 ◦ TR 명령을입력하면, 타이머동작재개메시지가출력되고, 7-Segment의시간이멈춘시점에서다시
감소동작을정상적으로재개하는지확인한다.
 ◦ 재개후타이머가정상적으로00.00까지감소완료되는지확인하고, 터미널에완료메시지가
출력되는지확인한다.


6. 스탑워치모드동작중M1 입력으로타이머모드진입
◦ 스탑워치모드에서PD0 버튼을눌러7-Segment에시간이증가하는지확인한다.
 ◦ M1 명령입력후터미널에타이머모드진입메시지가출력되는지확인한다.
 ◦ 7-Segment가00.00으로초기화(리셋) 되는지확인한다.
 7. 타이머모드동작중M0 입력으로스탑워치모드진입
◦ 타이머모드에서T30 명령을입력후,7-Segment에시간이감소하는지확인한다. 
◦ M0 명령입력후터미널에스탑워치모드진입메시지가출력되는지확인한다.
 ◦ 7-Segment가00.00으로초기화(리셋) 되는지확인한다.

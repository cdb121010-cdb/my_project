# 디지털 시스템 설계 (Digital System Architecture)

디지털 시스템 설계 과목의 실습 및 시험 프로젝트 공간입니다.

---

## 📂 프로젝트 및 과제 목록

- [**Midterm_Exam (중간과제: MicroBlaze 기반 스위치 및 UART LED 제어 시스템)**](Midterm_Exam/)
  - **개요**: MicroBlaze 프로세서 기반 16개 스위치 및 16개 LED 듀얼 모드 제어 SoC 시스템
  - **보드**: Xilinx Artix-7 (Nexys A7-50T)
  - **핵심 기능**: SW0 기반 스위치 직접 제어 모드 및 UART 원격 제어 모드 실시간 전환
  - [👉 중간과제 상세 문서 및 소스코드 바로가기](Midterm_Exam/)

- [**Final_Exam (기말과제: APB 기반 RGB LED 제어 시스템)**](Final_Exam/)
  - **개요**: AMBA APB 인터페이스 기반 6채널 RGB PWM 컨트롤러 IP 설계 및 MicroBlaze 프로세서 통합
  - **보드**: Xilinx Artix-7 (Nexys A7-50T)
  - **핵심 기능**: PC UART 시리얼 통신을 통한 2개 RGB LED 256단계 실시간 밝기/색상 제어
  - [👉 기말과제 상세 문서 및 소스코드 바로가기](Final_Exam/)
